# EduPuan: aplikasi web (Next.js)

Folder ini berisi aplikasi Next.js EduPuan (halaman, API, dan Puan AI).

Panduan lengkap (fitur, arsitektur, cara menjalankan, deployment) ada di **[README utama](../README.md)**.

Ringkas:

```bash
cp .env.example .env.local   # isi kuncinya, lihat README utama
npm install
npm run dev                  # http://localhost:3000
```
